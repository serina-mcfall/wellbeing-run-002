# Locked MVP
Promise: **Check in → understand what might help → choose support → optionally reflect → see history/insights.**

Required: Home; Check-in (mood, energy, sensory load, social battery, optional note, history); Journal plain-text CRUD; Companion via OpenRouter; Support (2/5/10m meditation, 2/5/10m movement, rain/ocean/fireplace/brown-noise); Insights with deterministic counts/history/distribution/usage; Jev choice only TALK/JOURNAL/MEDITATE/MOVE/SOUNDSCAPE/NOTHING; responsive installable PWA; minimal Supabase Auth; clearly labelled synthetic demo data only if needed.

Out: voice, wearables/health, SQLite/local-first sync, social/sharing, gamification, punitive streaks, rich text/photos/tags/search, advanced memory/RAG, sound mixer/streaming, native apps, complex notifications, OAuth providers, CMS, clinical diagnosis.

## PWA clarification
For Run 001, PWA means: responsive installable web application, valid manifest/icons, and usable standalone presentation. Offline-first data, background sync, and local-first replication are explicitly out of scope.

## Soundscape provenance
The four MVP soundscapes must use owned, public-domain, or appropriately licensed assets, with attribution/license recorded where required.
