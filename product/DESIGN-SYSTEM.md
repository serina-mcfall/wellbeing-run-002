# Cognitive & Sensory Design Contract
Calm, predictable, friendly, grounded, low-demand, not clinical.

Required: mobile-first (375px), generous whitespace, clear hierarchy, predictable navigation, one obvious primary action per area, muted/low-saturation palette with strong readable contrast, consistent spacing, restrained surfaces, concise non-judgmental language, progressive disclosure, user-controlled sound/motion, reduced-motion support, thumb-friendly controls, short readable blocks, left-aligned body text, comfortable line height/length, clear headings/labels.

Prohibited: flashing/pulsing; autoplay motion/audio; noisy backgrounds; excessive gradients/glass/shadows; dense dashboards; unnecessary badges; competing primary actions; colour-only meaning; guilt/streak/failure language; justified text; large italic/ALL-CAPS blocks; confetti; decorative motion.

Calm does NOT mean low contrast. Default UI is low-stimulation; do not build a second theme for MVP.
