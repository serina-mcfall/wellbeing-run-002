# AI
Companion via OpenRouter behind CompanionService: listen, reflect, ask, suggest approved low-stakes support. No diagnosis, hidden-cause claims, therapist impersonation, fabricated history, or causal claims from correlation.
Jev via OpenRouter Decisions API behind DecisionService. Product choices: TALK/JOURNAL/MEDITATE/MOVE/SOUNDSCAPE/NOTHING. Suggestions are not facts.
SQL/TypeScript computes analytics facts.
Control-plane Jev may advise task health HEALTHY/STRUGGLING/STALE/BLOCKED, event significance ROUTINE/NOTABLE/IMPORTANT/POTENTIAL_ESCALATION, next attention CONTINUE/RECHECK_SOON/REVIEW/FIXER/HUMAN_REVIEW. Supervisor validates. Jev never merges, kills workers, changes scope/providers, or contacts human.
